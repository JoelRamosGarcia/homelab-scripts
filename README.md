# homelab-scripts

Scripts bash que uso en mi VPS para mantenerlo vigilado y con copias de seguridad.

## Scripts

- **monitor.sh** — comprueba disco, RAM y contenedores Docker caídos. Se ejecuta cada 15 min con cron y guarda un log.
- **backup-portfolio.sh** — copia de la base de datos (MariaDB) y los archivos de WordPress. Cada noche, con rotación de 7 días.

## Tecnologías
Bash · Docker · cron · MariaDB
